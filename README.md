# Emergency Resource Locator

## Project Description

Emergency Resource Locator is a Streamlit-based application
that helps users find nearby emergency resources such as
hospitals, shelters, police stations and fire stations.

## Technologies

- Python 3.11
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Geopy
- Folium
- Streamlit-Folium
- SQLAlchemy
- SQLite

## Features

- Search emergency resources
- Select resource type
- Calculate distance
- Display nearby resources
- Interactive map
- SQLite database
- Simulated emergency-resource data

## Run

```bash
streamlit run app.py
